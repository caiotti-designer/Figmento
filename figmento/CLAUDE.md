# Figmento Plugin - Claude Code Notes

@../AGENTS.md

This directory is the current Figmento Figma plugin, not the older standalone screenshot-to-layout plugin.

## Current Architecture

- Build system: Plugma + Vite. `package.json` drives `prebuild`, `build`, `watch`, `typecheck`, `test`, and `lint`.
- Sandbox entry: `src/code.ts`, with command dispatch in `src/handlers/command-router.ts`.
- UI entry: `src/ui/index.ts`, with chat and bridge modules under `src/ui/`.
- Shared/generated knowledge:
  - `src/ui/tools-schema.generated.ts` is generated by `../scripts/generate-tool-schemas.ts`.
  - `src/knowledge/compiled-knowledge.ts` is generated by `scripts/compile-knowledge.ts`.
- The plugin talks to `figmento-ws-relay` over WebSocket. The relay can route direct chat turns or local agentic turns through Claude Code and Codex.

## Local Commands

```bash
npm run typecheck
npm test
npm run lint
npm run build
npm run watch
```

If global `npm` is broken, run the local binaries directly from `node_modules/.bin` and report that workaround.

## Figma Plugin Constraints

- Figma plugin iframes may not have reliable `localStorage`; wrap browser storage in safe helpers.
- External network domains must be listed in the Plugma manifest config inside `package.json`.
- Persist plugin settings through sandbox handlers and `figma.clientStorage`.
- Do not edit generated files by hand; update the generator or source data.
